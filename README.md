# Confidentiality

**A survival horror game developed by Zeplix Studios.**

Explore an abandoned hospital, uncover its secrets, and survive the dangers lurking inside.

> **Development Status:** Early Beta — v0.6  
> **Platform:** Windows PC  
> **Developer:** Zeplix Studios

## About the Game

*Confidentiality* is an atmospheric first-person survival horror game set inside an abandoned hospital.

Explore dark corridors, solve puzzles, discover hidden secrets, and avoid the mysterious Caretaker.

The game is actively being developed, with new features, improvements, and bug fixes introduced through updates.

## Latest Update — v0.6

### What's New
- **Expanded Exploration:** New hospital areas, puzzles, and objectives.
- **Improved Caretaker:** Enhanced enemy behaviour, detection, and hiding mechanics.
- **Gameplay Improvements:** Updated lighting, graphics settings, and performance optimisations.
